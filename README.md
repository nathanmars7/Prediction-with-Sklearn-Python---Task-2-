# Predicting bike-share rides

> **Archived learning exercise (2022).** Kept as-is; not maintained and not part of the current portfolio.

A worked example from the Anaconda Distribution sample notebooks: a Pittsburgh bike-share dataset, a look at the correlation between daily maximum temperature and number of rides, and a scikit-learn regression to predict rides from temperature. One notebook, `Predicting Bike Share Rides Task 2.ipynb`.

## Run it

Open the notebook in Jupyter with `pandas`, `matplotlib` and `scikit-learn` installed. The dataset is loaded inside the notebook.
